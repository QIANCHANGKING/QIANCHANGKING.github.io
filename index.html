Biography

个人简介

你好，我是 Ben（物理钱老师 / qianchangdtw）。目前从事高中物理教学辅导工作，长期带一对一及班课学生，覆盖力学、电磁学、热学与高三一轮体系化复习。

在此之前，我曾在菲律宾宿务的 3D Academy 工作，负责连接中文学员、外教团队与校方管理之间的跨文化沟通与教学支持。这段经历让我更加看重清晰、耐心的表达方式。

课堂之外，我喜欢研究高效学习工具、macOS / Linux 工作流以及极简静态建站，也热爱户外骑行。这个主页采用零框架单文件架构，直接托管在 GitHub Pages 上。
